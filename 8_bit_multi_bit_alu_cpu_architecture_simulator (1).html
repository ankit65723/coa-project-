Supported Assembly Instructions (ISA)

MOVI R0, 25 : Put number 25 into R0
MOV R1, R0 : Copy R0 into R1
ADD R0, R1 : R0 = R0 + R1
SUB R0, R1 : R0 = R0 - R1
AND / OR / XOR : Bitwise Logic
SHL R0 / SHR R0 : Shift bits Left/Right
STORE R0, 10 : Save R0 to RAM[10]
HLT : Stop the program
